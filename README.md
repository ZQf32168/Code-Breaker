## 安装与更新

在 Android 设备上下载并打开 APK。系统可能要求为浏览器或文件管理器允许“安装未知应用”；完成安装后可以关闭该权限。

更新已有正式版本时，请直接覆盖安装以保留本机进度。如无法安装，请联系开发者，不要先卸载或清除数据。卸载或清除应用数据会删除本机进度与设置。
